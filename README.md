# Standoff Tuner

Android-приложение для растяжения экрана (stretch) и оптимизации перед игрой в Standoff 2.
Root не нужен — команды выполняются через [Shizuku](https://shizuku.rikka.app/).

## Что делает

- **Растяжение** — меняет системное разрешение (`wm size`) на 4:3, 5:4, 16:10 или 16:9
  на время игры. Короткая сторона экрана сохраняется, длинная уменьшается.
- **Игровой режим** — `cmd game mode performance` (Android 12+).
- **Без анимаций** — анимации системы выключаются на время игры.
- **Максимальная частота экрана** — 90/120 Гц, если телефон поддерживает.
- **Закрытие фоновых приложений** перед запуском (по желанию).

После выхода из игры всё возвращается автоматически. Вернуть вручную можно кнопкой
в уведомлении или в приложении.

Файлы игры не изменяются, античит не обходится — меняются только системные настройки Android.
Тем не менее растяжение может считаться разработчиками игры нечестным преимуществом:
используйте на свой риск.

## Установка

1. Скачайте `.apk` со страницы [Releases](../../releases) и установите.
2. Установите Shizuku из Google Play и запустите его через «Беспроводную отладку»
   ([инструкция](https://shizuku.rikka.app/guide/setup/)). После перезагрузки телефона Shizuku нужно запускать заново.
3. Откройте Standoff Tuner, разрешите доступ к Shizuku, выберите профиль и нажмите «Запустить Standoff 2».

Если экран остался растянутым (например, приложение было закрыто системой), откройте Standoff Tuner
и нажмите «Вернуть всё как было». Крайний случай — через ADB: `adb shell wm size reset`.

## Сборка

```
./gradlew assembleRelease
```

Каждый push в `main` собирает APK в GitHub Actions (артефакт сборки).
Релиз: Actions → Build → Run workflow → укажите версию, например `v1.0.0`.
