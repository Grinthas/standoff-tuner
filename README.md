# Standoff Tuner

Android-приложение, которое готовит телефон к Standoff 2 на максимальном FPS.
Не нужны root, ADB и Shizuku.

## Что делает

- **Проверка готовности:** энергосбережение, частота экрана, анимации системы,
  свободная память, температура батареи и троттлинг. Для каждой проблемы — подсказка
  и кнопка, открывающая нужный экран настроек.
- **«Не беспокоить» на время игры:** уведомления не всплывают поверх игры;
  прежний режим возвращается, когда вы возвращаетесь в приложение.
- **Запуск Standoff 2** одной кнопкой.

Без root и ADB Android не позволяет обычным приложениям менять системные настройки
и закрывать чужие процессы (с Android 14), поэтому Standoff Tuner проверяет настройки
и ведёт к нужному экрану, а не меняет их сам. Файлы игры не изменяются.

## Установка

Скачайте `.apk` со страницы [Releases](../../releases) и установите.

## Сборка

```
./gradlew assembleRelease
```

Каждый push в `main` собирает APK в GitHub Actions (артефакт сборки).
Релиз: Actions → Build → Run workflow → укажите версию, например `v1.0.0`.
